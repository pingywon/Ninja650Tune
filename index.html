Digital archaeology

These maps were nearly lost. The project was rebuilt from recovered .pvm device captures, original change records, and 23 dated software backups — then reconciled into a clean version history with a SHA-256 manifest for every file.

It's honest about the gaps, too: two cumulative ZIPs from August 15, 2026 are still missing, a later rename gave two different maps the same "RC v1.0" label (untangled in the docs), and no file gets promoted to "known good" without the paper trail to back it.

Published copies were scrubbed of local paths and device identifiers hiding in unused notes bytes — original length, tables, and axes preserved, every changed offset recorded.

Kick the tires

A small Python toolkit (3.10+, zero dependencies) inspects, diffs, verifies, and packages the whole collection:

# check every hash in the manifest
python tools/pcv.py verify
# what did v1.3 actually change?
python tools/pcv.py diff maps/smooth-operator/SO_v1.0_KNOWN_GOOD.pvm \
                         maps/smooth-operator/SO_v1.3_TEST.pvm
# reproducible cumulative archive
python tools/pcv.py build
